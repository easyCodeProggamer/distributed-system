### Virtual Thread Demo

#### Step1: Download Jmeter
```
jmeter : https://jmeter.apache.org/download_jmeter.cgi
```

#### Step2: Unzip steps
```
click on zip file in download folder -> unzip -> go to bin -> windows bat file
```

#### Step3: Import jmeter-script.jmx into the jmeter

#### Step4: Click start(Green play button)
